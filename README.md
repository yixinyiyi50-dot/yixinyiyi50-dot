## 📌 项目展示

> 🔒 表示私有项目（涉及院内业务，暂未开源，可交流思路）

### 🔒 药品效期养护管理系统
面向摆药室的效期检查与养护全流程管理：效期预警、养护记录、月度检查台账自动生成，配套客户端安装程序与使用文档。
`Web` `C#` `Excel 自动化`

### 🔒 摆药室管理系统
摆药/加药计划管理：库存查询、加药计划模板、DTA 药品记录，客户端 + 服务端架构，绿色版一键部署。
`C#` `JavaScript` `部署脚本`

### 🔒 药房报损登记系统
药品报损的在线登记、审核与标签打印，替代手工纸质台账，数据自动汇总到 Excel。
`Flask` `Python` `标签打印`

### 🔒 HIS 数据接口服务
对接 HIS 的数据中间层：药品目录同步、门诊/住院/麻精药品发药数据查询，部署于药剂科服务器，含防火墙配置、开机自启、日志轮转等生产化细节。
`FastAPI` `Python` `生产部署`
